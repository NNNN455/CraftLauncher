Экземпляры

Каждая версия — в своей папке. Миры, моды и конфиги не конфликтуют между собой.

🧩

Мод-браузер

Поиск модов с Modrinth прямо в лаунчере. Фильтры по категориям, автозагрузка зависимостей.

🎨

Скины Ely.by

Интеграция с Ely.by. Превью скина, авторизация, поддержка 2FA, скины в игре.

🌐

Сетевая игра

Играй с друзьями через Radmin VPN или Hamachi. Автоопределение IP и быстрое подключение.

⚙

Forge и Fabric

Установка загрузчиков прямо в лаунчере. Уважение к Forge — выбор между авто и ручной.

🖥

Консоль логов

Real-time вывод Java с подсветкой ошибок, предупреждений и успешных событий.

💾

Авто RAM

Лаунчер сам определяет объём оперативной памяти и подстраивает слайдер.

🎨

Кастомизация

Свой фон, тёмная/светлая/системная тема, F11 для полного экрана.
